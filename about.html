My Gallery

About This Project

My Gallery is a simple image slider website built using HTML, CSS, and JavaScript. It features an image carousel powered by Swiper.js and includes an image upload form for future enhancements.

The purpose of this project is to showcase interactive front-end components, improve layout design, and explore image-handling capabilities in a browser.

Developed by [Peter Kihara]. Feel free to explore, upload, and enjoy the gallery.
