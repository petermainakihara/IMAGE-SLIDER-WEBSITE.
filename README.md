# My Gallery - Image Slider Website 🎨

Welcome to **My Gallery**, a simple and interactive image slider web application built using **HTML**, **CSS**, and **JavaScript**. This project showcases front-end development skills including layout design, interactivity, and basic file handling.

## 🚀 Features

- 🎞️ Responsive image slider powered by [Swiper.js](https://swiperjs.com/)
- 🖼️ Upload form to simulate image additions (functionality placeholder for now)
- 🔒 Simple login form (non-functional – for UI demonstration)
- 📄 About page with project details
- 💻 Clean layout with responsive design

## 📂 File Structure

/project-root │ ├── index.html # Home page with image slider ├── result.html # Upload success page ├── about.html # Project information ├── style.css # Styling for the website ├── index.js # JavaScript for interactivity ├── /images 2/ # Folder containing images and logo


## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- [Swiper.js](https://swiperjs.com/) for the carousel functionality
